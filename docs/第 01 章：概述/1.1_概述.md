# 概述

Spring Authorization Server  是 Spring 家族的授权服务器组件，之前是和 spring security 放到一起， 后来就单独抽离出来， 成为了 Spring 的顶级组件之一。

## 本章说明

主要说说为什么会有 Spring Authorization Server ？

Spring Authorization Server  都有哪些使用案例？

 Spring Authorization Server  对应的功能列表？

Spring Authorization Server是一个框架，提供了对 OAuth 2.1 和 OpenID Connect 1.0 规范以及其他相关规范的实现。它基于 Spring Security 构建，为构建 OpenID Connect 1.0 身份提供者和 OAuth2 授权服务器产品提供了安全、轻量级且可定制的基础。



使用场景
以下列表提供了一些在使用 Spring Authorization Server 与开源或商业 OAuth2 或 OpenID Connect 1.0 提供商产品相比时的用例。

当需要高级定制场景时，可以完全控制配置和自定义。
相对于包含所有“花哨功能”的商业产品，更倾向于轻量级授权服务器。
可能在软件许可和/或托管成本方面节省费用。
开发期间使用熟悉的Spring编程模型快速启动并易于使用。
