# 准备开始

接下来， 我们来创建我们第一个基于 Spring Authorization Server 的应用程序。 

## 要求

Spring Authorization Server 需要 Java 17 或更高版本的运行时环境。

虽然 Spring Authorization Server 支持不与 Spring Boot 绑定使用， 但还是推荐使用 Spring Boot 构建应用程序， 并使用 `start.spring.io` 生成一个基础的项目。

加入 Maven 的依赖

```xml
<dependency>
    <groupId>org.springframework.security</groupId>
    <artifactId>spring-security-oauth2-authorization-server</artifactId>
    <version>1.3.3</version>
</dependency>
```
